> Helping everyone list their software in AWS, Azure, and GCP Marketplaces — **for free**.

## 💡 Why This Exists

Many companies charge **₹50,000 to ₹5,00,000+** just to *guide* someone to list their product in a cloud marketplace.

But the truth is:

> **Anyone can list their product** — SaaS, AMI, VM, Kubernetes app, container image, ML model, paid API —  
> *if they know the steps and requirements.*

The process is confusing only because:
- Information is scattered
- Documentation is vague
- Marketplace rules differ by product type
- Consultants make it sound more complex than it is

So this community exists to **change that**.

We help:
- Independent developers
- Small startups
- ISVs (Independent Software Vendors)
- Students & hobby builders
- Open-source creators
- First-time marketplace publishers

**Without charging anything.**

## 🚀 What You Can List in Marketplaces

| Marketplace | Supported Product Types |
|------------|------------------------|
| **AWS Marketplace** | SaaS, AMI, Container Images (ECR), Kubernetes (EKS Add-ons), Metered billing, Contract billing |
| **Azure Marketplace** | SaaS Offers, VM Offers, Managed Apps, Container Apps, Co-Sell programs |
| **GCP Marketplace** | SaaS, Kubernetes Apps, Container registries, VM images, Billing integrated solutions |

If the marketplace supports it → **you can list it.**  
This community helps you do it successfully.
