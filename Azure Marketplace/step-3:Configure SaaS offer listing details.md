# 🧾 Step 3: Configure SaaS Offer Listing Details

The information you provide on the **Offer listing page** for your **Software as a Service (SaaS)** offer will be displayed in **Microsoft Marketplace** online stores.  
This includes your **offer descriptions**, **screenshots**, and **marketing assets**.

---

> 💡 **Note**  
> Offer listing content doesn’t have to be in English if your description begins with:  
> “This application is available only in [non-English language].”  
>  
> You can also include a **Useful Link URL** to content in another language.

---

## 🛒 Marketplace Details

On the **Offer listing** page, under **Marketplace details**, complete the following fields.  
To learn more about these required details, see [Offer listing details](https://learn.microsoft.com/en-us/azure/marketplace/partner-center-portal/offer-listing-details).

### 🧩 Name
- Pre-filled from the value you entered earlier in the **New offer** dialog box.  
- You can change this name at any time.

### 🔍 Search Results Summary
- Enter up to **100 characters**.  
- This text appears in **Marketplace search results**.

### 📝 Description
- Enter a detailed description for your offer.  
- Use the **rich-text editor** or HTML tags to format content.  
- Maximum **5,000 characters** (including spaces and markup).  
- For supported HTML formatting, see [HTML tags supported in Microsoft Marketplace offer descriptions](https://learn.microsoft.com/en-us/azure/marketplace/partner-center-portal/html-tags).

### 🚀 Getting Started Instructions
- Provide instructions to help customers connect to your SaaS offer.  
- You can include **links to external documentation**.  
- Limit: **3,000 characters**.

### 🏷️ Search Keywords (Optional)
- Enter up to **three keywords** customers can use to find your offer.  
- The offer name and description are automatically indexed — no need to repeat them.

### 🔒 Privacy Policy Link
- Enter a valid **HTTPS URL** to your organization’s privacy policy.  
- You are responsible for ensuring compliance with privacy laws and regulations.

---

## 🔗 Add Supplemental Links (Optional)

Add links to additional online documentation.

1. Under **Useful links**, select **Add a link**.  
2. Enter a **Title** (up to 255 characters) and the **HTTPS URL** to the document.  
3. Repeat for multiple links if needed.

---

## 👤 Enter Contact Information

Under **Contact information**, provide the following details:

| Contact Type | Required | Purpose |
|---------------|-----------|----------|
| **Support Contact** | ✅ Yes | For general support questions. |
| **Engineering Contact** | ✅ Yes | For technical issues or certification inquiries. |
| **CSP Program Contact** | Optional | For Cloud Solution Provider program support/business issues. |

Each contact includes:
- Name  
- Email address  
- Phone number  

For the **Support Contact**, also include:
- A **Support URL** (publicly visible).

---

### 🌐 Extend to the CSP Program (Optional)

To extend your offer to the **Cloud Solution Provider (CSP)** program:
- In the **CSP Program Marketing Materials** box, add a link to your **marketing assets**.

> 💡 **Note:**  
> The CSP program allows resellers to **bundle, market, and resell** your offer to a broader audience.  
> See [Go-to-market with Microsoft](https://learn.microsoft.com/en-us/partner-center/marketplace-publisher-guide) for details.

---

## 📎 Add Marketing Documents

You must upload **1 to 3 marketing documents** in **PDF** format.

1. Under **Supporting documents**, drag and drop your PDF file.  
2. In the **Name** box, enter a title — customers will see this on your offer’s “Details” tab.  
3. Repeat to add additional documents.

---

## 🖼️ Add Marketplace Media

> ⚠️ **Important:**  
> Create accessible, inclusive media assets.  
> See [Create accessible media](https://learn.microsoft.com/en-us/partner-center/accessibility-media).

---

### 🪞 Add Logos
Under **Logos**, upload a **Large PNG** image between **216×216** and **350×350 pixels** (equal width and height).  

Partner Center automatically generates:
- **Small (48×48)**  
- **Medium (90×90)**  
versions — which you can replace later.

**Logo usage:**
| Size | Display Location |
|-------|------------------|
| Small | Microsoft Marketplace search results & main page |
| Medium | Azure resource creation screen |
| Large | Offer listing page in Microsoft Marketplace |

---

### 📷 Add Screenshots
You must include **at least 1 and up to 5 screenshots**.

**Requirements:**
- PNG format  
- Size: **1280×720 pixels**

**Steps:**
1. Under **Screenshots**, drag and drop your image.  
2. Next to **Add image caption**, click the ✏️ Edit icon.  
3. Enter a descriptive caption.  
4. Repeat for additional images.

---

### 🎬 Add Videos (Optional)

Add **YouTube** or **Vimeo** videos that showcase your offer.  
You can include up to **4 videos**.

**Steps:**
1. Select **Add video link**.  
2. Enter the **Name** and **Video URL**.  
3. Upload a **PNG thumbnail** (1280×720 pixels).  
4. Repeat for more videos.

**Accepted video URL formats:**
| Platform | Example URL |
|-----------|--------------|
| YouTube | `https://www.youtube.com/watch?v=[VIDEO_ID]` |
| Vimeo | `https://vimeo.com/[VIDEO_ID]` |
| Vimeo (Company Account) | `https://vimeo.com/[COMPANY_ACCOUNT_ID]/[VIDEO_ID]` |
| Vimeo (Player) | `https://player.vimeo.com/video/[VIDEO_ID]` |

> 💡 **Tip:**  
> If uploads fail, ensure your network allows  
> `https://upload.xboxlive.com`, which Partner Center uses for media uploads.

---

### 💾 Save Progress
Before proceeding to the next tab (**Preview audience**), select **Save draft** to ensure all your listing data is stored.
