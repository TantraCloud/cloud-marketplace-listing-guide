# 🤝 Contributing to Cloud Marketplace Listing Guide

We love your input! We want to make contributing to this project as easy and transparent as possible.

## 🪄 How to Contribute
- Fork the repo and create your branch from `main`
- Improve documentation or fix typos
- Add examples, screenshots, or clarifications
- Submit a pull request

## 🧱 Code / Docs Standards
- Use simple, clear Markdown.
- Keep filenames consistent (`Step-1.md`, `Step-2.md`).
- Avoid long paragraphs — prefer bullet points.

## 💬 Reporting Issues
Use the [Issues tab](../../issues) to:
- Report broken links
- Suggest new guides
- Propose improvements

## ❤️ Our Promise
Every contributor is respected.  
No contribution is too small.
